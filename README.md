# SIYAH — Premium Home Page (Acdyon Technologies Take-Home Assessment)

This repository contains the complete frontend submission for **Track 2: Premium Home Page** (Acdyon Technologies Assessment).

## Project Overview

- **Live Landing Page**: `index.html` (Single self-contained HTML/CSS/JS file for instant deployment)
- **Engineering Decisions Document**: `DECISIONS.md`
- **Brand Context**: **SIYAH** (Indian Ethnic Wear: Sarees, Kurtis & Suit Sets)
- **Key Value Prop**: *"Ethnic wear, minus the boring price tag"*

---

## Key Features Built

1. **Fluttering Saree Pallu Ambient SVG**: Dual-layer swaying SVG ribbons with dotted zari gold borders running at 60 FPS without external heavy 3D libraries.
2. **Custom Price-Tag CTA Buttons**: Styled via CSS `clip-path` and wired with smooth JS scroll handlers.
3. **Honesty-First Banner**: Zero fake testimonials, fake user counts, or fake logos — leaning 100% on transparent early-stage brand positioning.
4. **Product Showcase with Fabric Swatch Hover**: Interactive product cards featuring fabric texture patterns and hover-reveal color swatch strips.
5. **Konami Code Easter Egg**: Secret bonus triggered by pressing `↑ ↑ ↓ ↓ ← → ← → B A`.

## Quick Local Preview

Simply double-click `index.html` to open it in any modern browser, or serve it via python:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deployment (Free Hosting)

### Option 1: Netlify Drop (Fastest - 10 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the project folder containing `index.html`.
3. Copy the live deployed URL for your Google Form submission!

### Option 2: Vercel / GitHub Pages
1. Push this folder to a public GitHub repository.
2. Import the repository into Vercel or enable GitHub Pages under **Repo Settings > Pages**.
